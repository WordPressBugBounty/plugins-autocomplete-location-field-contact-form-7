### How It Works

1. Install and activate the plugin.
2. Navigate to **Contact → Google Place API** in your WordPress admin.
3. Paste your **Google Places API Key**.
4. Open any **Contact Form 7** form editor.
5. Click **"Field Autocomplete"** to insert the location field shortcode.
6. Save the form and publish your page.

That's it — your form now has intelligent address autocomplete!

== Installation ==

**Option 1: Install via WordPress Admin (Recommended)**

1. Go to **Plugins → Add New** in your WordPress dashboard.
2. Search for **"Autocomplete Location Field for Contact Form 7"**.
3. Click **Install Now**, then **Activate**.
4. Navigate to **Contact → Google Place API** and enter your API key.

**Option 2: Manual Installation**

1. Download the plugin `.zip` file.
2. Upload the extracted folder to `/wp-content/plugins/`.
3. Activate the plugin from **Plugins → Installed Plugins**.
4. Add your Google API key under **Contact → Google Place API**.
5. Open a Contact Form 7 form and insert the **Field Autocomplete** tag.

== Frequently Asked Questions ==

= Do I need a Google API key to use this plugin? =
Yes. A valid Google Places API key is required. You can generate one for free at [Google Cloud Console](https://console.cloud.google.com/). Make sure the **Places API** is enabled and billing is set up in your project.

= How do I add the autocomplete field to my form? =
Open your Contact Form 7 form editor and click the **"Field Autocomplete"** button in the tag generator toolbar. The shortcode will be inserted automatically.

= The autocomplete is not showing suggestions. How do I fix it? =
Open your browser's developer tools (F12) and check the **Console** tab for errors. Common causes include:
- Incorrect or missing API key
- Places API not enabled in Google Cloud Console
- Billing not activated on your Google Cloud account

= Can I restrict autocomplete results to a specific country? =
Yes — country restriction is available in the [Pro version](https://www.codesmade.com/store/autocomplete-location-field-contact-form-7-pro/).

= Can I capture address parts like city, state, and postcode in separate fields? =
Yes — separate address components are a [Pro feature](https://www.codesmade.com/store/autocomplete-location-field-contact-form-7-pro/).

= Is this plugin compatible with the latest version of WordPress? =
Yes. The plugin is tested up to WordPress 6.9.1 and actively maintained.
